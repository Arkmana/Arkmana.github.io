关于

这里是 Arkmana 的个人数字空间，用来存放技术笔记与文档。

想加一篇新文章：在 GitHub 上打开 src/content/posts/，新建一个 .md文件，按模板填好开头字段后 Commit —— 构建与部署由 GitHub Actions 自动完成，约一分钟上线。

技术栈

  • Astro 7 + Vue 3.5，islands 架构，交互组件按需水合
  • Vite 8 / TypeScript 5.9 / Pinia 4
  • Tailwind CSS 4，牛皮纸主题
  • 内容层：Content Collections + Zod 校验
  • 搜索：Pagefind 纯静态索引

URL 规则

  • 文章路由 = 文件名的拼音：数据结构.md → /posts/shu-ju-jie-gou/
  • 标签与分类同样转拼音：中文 → /tags/zhong-wen/；英文数字原样保留
  • 想固定 URL，在 frontmatter 写 slug: my-url

Markdown 扩展语法

  • 数学公式：$行内$ 与 $$块级$$（KaTeX）
  • 提示块：> [!NOTE]、[!TIP]、[!WARNING]、[!DANGER]、[!IMPORTANT]、[!INFO]
  • 代码块：行号、长代码折叠、语言角标、一键复制（Expressive Code）

已实现的功能

  • 分页、标签页、分类页、归档
  • 文章目录（滚动高亮）、上一篇 / 下一篇、阅读时长与字数
  • 全文搜索、RSS、sitemap
  • 阅读进度条、回到顶部、深浅色切换
  • 代码块语言角标 + 一键复制
  • 构建期图片压缩与懒加载、窄屏表格横向滚动

换纸色

改 src/styles/global.css里 :root的变量即可整体换色。下面几套是备选：

  • 牛皮纸（当前）--paper-bg: #f2e6cf · --paper-accent: #7a5a2e
  • 明黄纸--paper-bg: #fffbe6 · --paper-accent: #b8860b
  • 米黄宣纸--paper-bg: #faf5e6 · --paper-accent: #9a6b2f
  • 淡青稿纸--paper-bg: #f4f7ee · --paper-accent: #4a6b3a

颗粒强度由 --paper-grain-opacity 控制，设成 0 即可关掉纸张纹理。
