为什么是 Astro

写作量一旦上到几百篇，最先出问题的不是写作本身，而是 构建时间 和 内容一致性。

两者在这两件事上的做法不同：

能力HexoAstro
内容层无校验Content Collections + Zod 类型校验
代码高亮highlight.jsShiki（VS Code 同款）
图片优化无astro:assets 自动压缩转 WebP
加交互组件困难可直接混用 React / Vue / Svelte
构建全量重生成Vite 驱动
